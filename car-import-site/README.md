# Japanese Vehicle Import Site

A static site for a Japan-to-Zimbabwe car import business. It has a price search, a landed-cost calculator that compares routes, and WhatsApp enquiries. There is no build step: open `index.html` or upload the folder to any static host.

Before launch, edit these files:
- `assets/config.js`: brand, contacts, duty rates (the rates are placeholders, so verify them)
- `data/vehicles.js`: your price list
- `data/routes.js`: freight, port and transit costs

Planning notes live in `obsidian/`. Open that folder as an Obsidian vault and start from "Car Import Business - Map".
