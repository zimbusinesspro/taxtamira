# Website Features
Back to [[Car Import Business - Map]]

Modelled on the competitor's offering (a price search and route-cost calculator), built from scratch with original code, text and branding.

1. **Price search**: filter by make, body, fuel, budget and model. Each price is a *maximum* indicative FOB price.
2. **Route cost comparison**: one card per route, with the cheapest one marked. See [[Pricing and Landed Cost]].
3. **WhatsApp**: header button, floating button, and an enquiry form that opens WhatsApp with the details filled in.
4. **Optional external form**: set `enquiryFormUrl` in `assets/config.js` (e.g. a Google Form).
5. **How it works**: see [[Import Process]].

Files: `index.html`, `assets/config.js`, `assets/app.js`, `assets/styles.css`, `data/vehicles.js`, `data/routes.js`.
